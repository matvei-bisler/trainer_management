# Запуск тренажёра: пошаговая инструкция

Как это устроено: приложение на Streamlit хранит разметку, тесты и результаты в Google-таблице.
Прямого доступа к таблице у приложения нет. Оно отправляет запросы маленькому скрипту
(Apps Script), который живёт внутри таблицы и записывает данные от вашего имени.
Запросы подписываются секретным токеном, поэтому посторонние писать в таблицу не могут.

```
Студент → Streamlit (сервер) → HTTPS + токен → Apps Script → Google-таблица
```

Всё бесплатно: Google Cloud Console и сервисный аккаунт не нужны.

Всё, что нужно сделать, — это части 1–3. Часть 1 займёт около 10 минут, делается один раз.

---

## Часть 1. Google-таблица и скрипт

> Используйте **личный аккаунт Gmail**. Корпоративные и университетские аккаунты Google Workspace
> часто не разрешают доступ «Все», и тогда приложение не сможет достучаться до скрипта.

**1.1. Создайте таблицу.** Откройте https://sheets.new и назовите её, например,
«Тренажёры ФОС — данные». Листы создавать не нужно, скрипт сделает их сам.
Одна таблица обслуживает все тренажёры (см. «Несколько программ в одной таблице»).

**1.2. Откройте редактор скриптов.** В таблице выберите меню **Расширения → Apps Script**.
Откроется редактор с файлом `Код.gs` (или `Code.gs`).

**1.3. Вставьте код.** Удалите в редакторе всё, что там есть (`function myFunction() {}`),
и вставьте целиком содержимое файла [`apps_script/Code.gs`](apps_script/Code.gs).
Нажмите 💾 (или Cmd+S).

**1.4. Задайте токен.**
1. Слева нажмите ⚙️ **Настройки проекта**.
2. Внизу в разделе **Свойства скрипта** нажмите **Добавить свойство скрипта**.
3. Свойство: `TOKEN`. Значение: строка из поля `token` в файле `.streamlit/secrets.toml`
   этого проекта (она уже сгенерирована). Копируйте без кавычек.
4. Нажмите **Сохранить свойства скрипта**.

**1.5. Выдайте скрипту доступ к таблице.**
1. Слева нажмите **< > Редактор**.
2. В выпадающем списке функций на панели сверху выберите `setup` и нажмите **▷ Выполнить**.
3. Google попросит разрешение: **Проверить разрешения** → выберите свой аккаунт.
4. Появится предупреждение «Приложение не проверено». Это нормально, скрипт ваш собственный.
   Нажмите **Дополнительные настройки** → **Перейти на страницу «…» (небезопасно)** → **Разрешить**.
5. Внизу в журнале должно появиться «Готово: доступ выдан, TOKEN задан».
   Листы `reviews`, `tests`, `attempts` появятся в таблице сами при первой записи.

**1.6. Опубликуйте скрипт как веб-приложение.**
1. Справа вверху нажмите **Начать развертывание → Новое развертывание**.
2. Рядом с «Выберите тип» нажмите ⚙️ → **Веб-приложение**.
3. Заполните:
   - Описание: любое, например `v1`;
   - **Запуск от имени: Я** (ваш email);
   - **У кого есть доступ: Все**.
4. Нажмите **Начать развертывание**.
5. Скопируйте **URL веб-приложения**. Он заканчивается на `/exec`.

**1.7. Проверьте.** Откройте этот URL в браузере. Должно показаться:
```
{"ok":true,"service":"trainer-storage","version":2}
```
Если показывается страница входа в Google, значит, на шаге 1.6 не выбран доступ «Все».

## Часть 2. Подключение приложения (на вашем компьютере)

**2.1.** Откройте `.streamlit/secrets.toml` и вставьте URL из шага 1.6 в поле `url`:
```toml
[apps_script]
url = "https://script.google.com/macros/s/…/exec"
token = "…"   # уже заполнено, не трогайте
```
Там же в разделе `[passwords]` задайте пароли для каждой страницы эксперта: `review` (разметка), `builder` (конструктор), `results` (результаты). Пароль одной страницы не открывает другие.

**2.2.** Запустите приложение:
```bash
cd <папка тренажёра> && streamlit run app.py
```

**2.3.** Проверьте: в боковой панели должно быть написано **«Хранилище: Google Sheets»**.
Создайте пробный тест в «Конструкторе тестов», и в листе `tests` таблицы появится строка.

## Часть 3. Публикация в интернете (Streamlit Community Cloud, бесплатно)

Чтобы студенты могли открывать тесты по ссылке, приложение должно работать не только на вашем компьютере.

**3.1. Создайте на GitHub приватный репозиторий.** Он обязательно должен быть **Private**:
в Excel лежат ключи ответов, и в публичном репозитории их увидит кто угодно.

**3.2. Загрузите в репозиторий** содержимое папки `trainer`:
`app.py`, `program.toml`, `check_bank.py`, `lib/`, `views/`, `requirements.txt`, `.gitignore`
и файлы Excel и учебного плана, указанные в `program.toml`.
Файл `.streamlit/secrets.toml` не загружайте, он в `.gitignore`.

**3.3.** Зайдите на https://share.streamlit.io через GitHub → **Create app** → **Deploy a public app from GitHub**:
- Repository: ваш репозиторий, Branch: `main`, Main file path: `app.py`;
- **Advanced settings** → Python version: по умолчанию (приложение проверено на 3.14);
- **Secrets**: вставьте всё содержимое вашего `.streamlit/secrets.toml`.

Нажмите **Deploy**.

**3.4.** Когда приложение запустится, скопируйте его адрес (`https://….streamlit.app`) и замените
`app_url` в Secrets (**Settings → Secrets** приложения). После этого ссылки на тесты в конструкторе
станут полными.

> Несмотря на «public app», код и Excel остаются в приватном репозитории. Публичен только
> сам сайт, как и нужно для студентов. Экспертные страницы закрыты паролем.

## Как этим пользоваться

| Кто | Что | Где |
|---|---|---|
| Эксперт | Размечает вопросы светофором | «Разметка вопросов» (пароль) |
| Вы | Собираете тест и получаете ссылку `…/?test=abc123` | «Конструктор тестов» (пароль) |
| Студенты | Открывают ссылку, вводят ФИО и направление, проходят тест | ссылка на тест |
| Вы | Смотрите результаты и скачиваете Excel | «Результаты» (пароль) или прямо в Google-таблице |
| Все | Тренируются на банке вопросов | «Тренажёр» (без пароля) |
| Все | Просматривают вопросы с ответами, ищут по тексту, запускают тренировку по подборке | «Банк вопросов» (без пароля) |

Ответы в «Банке вопросов» можно скрыть, например на время контрольных: добавьте в Secrets
```toml
[student_bank]
show_answers = false
```
Вопросы останутся видны, ответы — нет. Тесты собираются из того же банка, так что с открытыми
ответами студенты могут их заучить.

## Если что-то пошло не так

| Симптом | Причина и что сделать |
|---|---|
| В боковой панели «Хранилище: локальные CSV» | В `secrets.toml` пустой `url` или `token`. На Streamlit Cloud проверьте Settings → Secrets |
| «Apps Script вернул не JSON» | Доступ в развёртывании не «Все» или адрес не заканчивается на `/exec` (шаги 1.6–1.7) |
| «Apps Script: forbidden» | Токены не совпадают: сравните `token` в secrets и свойство `TOKEN` в скрипте (шаг 1.4) |
| «TOKEN is not set in script properties» | Не выполнен шаг 1.4 |
| Изменили код скрипта, а работает по-старому | Нужна новая версия: **Начать развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. Адрес `/exec` не изменится |
| На странице разметки «Скрипт в Google-таблице устарел» | В таблице старая версия `Code.gs` — см. «Обновление скрипта» ниже |
| На странице разметки или конструктора «❗ В банке вопросов проблем: …» | Ошибки в Excel: откройте список, там номера строк. Исправьте и проверьте `python check_bank.py` |
| Приложение на Streamlit Cloud «спит» | Бесплатные приложения засыпают после ~12 часов без посещений. Первый зашедший нажимает «Yes, get this app back up», запуск занимает около 30 секунд. Перед тестом откройте приложение сами |

## Важно знать

- **Столбец `qid` в Excel не трогайте.** Это постоянный номер вопроса: по нему к вопросу
  привязаны разметка, тесты и попытки. Текст, варианты и ключ править можно — связи сохранятся.
- **Данные редактируются прямо в таблице.** Например, можно удалить пробную попытку.
  Не переименовывайте листы и не меняйте названия столбцов в первой строке.
  Свои столбцы (например, «заметки») добавлять можно — приложение их не сотрёт.
- **Лимиты бесплатного Apps Script** с запасом покрывают десятки студентов одновременно.
  Каждое сохранение занимает 1–2 секунды.

## Правка банка вопросов

Банк лежит в файле Excel, указанном в `program.toml` (`excel`), лист `assessment`:
столбцы `Q`, `Q_opt`, `A`, `ID`, `qid`.

> Это **копия** Excel из `Typst/raw_data`, и в ней есть столбец `qid`, которого нет в исходнике.
> Правьте вопросы именно в этой копии. Если перенести сюда новую выгрузку из Numbers, `qid`
> пропадёт: `check_bank.py --fill` восстановит его для неизменённых вопросов, но у вопросов,
> исправленных в Numbers, связь с разметкой и тестами потеряется.

**Цикл работы с экспертом:**

1. Эксперт размечает вопросы в «Разметке вопросов».
2. Вы скачиваете **«Excel с разметкой»** (вкладка «Сводка и выгрузка»). В нём рядом с каждым
   вопросом его оценка, проблемный фрагмент, комментарий и предлагаемая редакция, а также `qid`.
3. В основном Excel находите вопрос по `qid` (Ctrl+F) и правите `Q`, `Q_opt`, `A`. **`qid` не меняйте.**
4. Проверяете банк:
   ```bash
   python check_bank.py
   ```
   Команда покажет ошибки с номерами строк: ключ ссылается на несуществующий вариант,
   сломан формат «1 — Б; 2 — А», повторился `qid` и т. п.
5. Отправляете Excel в репозиторий. Streamlit Cloud пересоберёт приложение примерно за минуту.
   В это время идущие тесты прервутся, поэтому публикуйте правки, когда никто не сдаёт.
6. У исправленных вопросов в разметке появится статус **🔁 «Изменён после оценки»**: эксперт видит,
   что именно поменялось, свои прежние замечания и оценивает вопрос заново.
   Отберите такие вопросы фильтром «Статус → 🔁».

**Новый вопрос:** добавьте строку, `qid` оставьте пустым и выполните
```bash
python check_bank.py --fill
```
Команда впишет `qid` новым вопросам и ничего больше в файле не тронет.

**Скопировали строку, чтобы сделать похожий вопрос?** Очистите в копии `qid` и выполните `--fill`.
Иначе у двух вопросов будет один `qid`, и `check_bank.py` покажет ошибку.

**Удалить вопрос** можно просто удалив строку. В старых тестах и результатах он останется
с пометкой «удалён из банка», баллы сохранятся.

**Что будет с тем, что уже есть:**

| Где | Что происходит после правки вопроса |
|---|---|
| Тренажёр | Сразу новая версия |
| Разметка | Статус 🔁, нужно оценить заново. До повторной оценки вопрос выдаётся студентам |
| Созданные тесты | Показывают новую версию. В «Мои тесты» видно, сколько вопросов исправлено или удалено после создания |
| Прошлые попытки | Баллы не меняются. В разборе и в выгрузке помечено «исправлен после сдачи» |

**Вопросы с ошибками** (их показывает `check_bank.py` и список «❗» на страницах эксперта)
не выдаются в тренажёр и новые тесты, пока их не исправят.

## Обновление скрипта Google

Нужно, когда меняется `apps_script/Code.gs` (сейчас версия 2). Адрес `/exec` и токен не меняются.

1. Откройте таблицу → **Расширения → Apps Script**.
2. Замените весь код содержимым `apps_script/Code.gs` и сохраните (Cmd+S).
3. **Начать развертывание → Управление развертываниями** → ✏️ (карандаш) → **Версия: Новая версия** → **Развернуть**.
4. Откройте адрес `/exec` в браузере: должно быть `"version":2`.

Версия 2 сама дописывает новые столбцы в листы. Следующие доработки приложения, скорее всего,
обновления скрипта уже не потребуют.

## Несколько программ в одной таблице

Код у всех тренажёров одинаковый. Программу определяет файл `program.toml`:

```toml
code = "38.03.02"                        # в заголовке приложения
name = "Менеджмент · …"                  # подпись в боковой панели
excel = "38.03.02_2024_add.xlsx"         # банк вопросов
plan = "2024_38.03.02_long.csv"          # учебный план (export/…/long.csv)
table_prefix = "mgmt_"                   # листы: mgmt_reviews, mgmt_tests, mgmt_attempts
```

Все тренажёры пишут в **одну** Google-таблицу через **один** скрипт, каждый в свои листы.
У тренажёра 50.04.01 префикса нет (листы `reviews`, `tests`, `attempts`).
В Secrets у них одинаковые `url` и `token`, а пароли и `app_url` — свои.

**Новая программа:** скопируйте папку тренажёра без данных, положите Excel и `long.csv` программы,
поправьте `program.toml` (префикс — новый, только строчные латинские буквы и `_`), выполните
`python check_bank.py --fill`, создайте приватный репозиторий и приложение на Streamlit Cloud.

**Доработка кода** делается в одном тренажёре и копируется в остальные: всё, кроме
`program.toml`, Excel, плана и `.streamlit/secrets.toml`.
